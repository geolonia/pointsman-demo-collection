# Tech stack

- TypeScript Cloudflare Worker (`wrangler.jsonc`); tests with vitest and `@cloudflare/vitest-plugin`; Node >=24, pnpm (`packageManager` in package.json).
- Static page in `site/`, no bundler. Broker = GeonicDB (NGSI-LD), reached through the FIWARE bridge from the engine.
- `engine/` is git-ignored: a checkout of the pinned engine commit, or a link to a local engine clone. Its code is part of the build; don't edit it from here.
- `worker-configuration.d.ts` is generated by `wrangler types` and git-ignored.

Serena: `typescript` language server.
