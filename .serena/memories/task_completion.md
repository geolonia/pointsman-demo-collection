# Done checklist

- `pnpm check` passes against the pinned engine (not a linked local clone).
- Behaviour change has a test in `test/`.
- Profile or case change: README decision tables still match; private deployment copy updated.
- Setting, secret, queue or cron change: README "Setup" and `wrangler.jsonc` comments still match.
- `engine.json` bump: engine change merged and released first.
