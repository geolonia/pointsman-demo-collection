# pointsman-demo-collection

Demo of Pointsman with an NGSI-LD context broker (GeonicDB) for collection requests: booking, operations and crew apps around one broker.

This repository was scaffolded by Geolonia Backstage.

## Getting started

- Update this README with setup instructions.
- Implement your website code.
- Keep `catalog-info.yaml` up to date.

Like the other Pointsman demos, this repository has no TechDocs: the README is its documentation.
